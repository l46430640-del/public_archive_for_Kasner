# Scientific provenance

The public package was assembled from a frozen, publication-ready scientific
state. Only the following mathematical lineage is retained:

1. Four-dimensional Einstein-Maxwell-scalar action and its spherical
   scalarized backgrounds.
2. The two-channel odd quadratic action and regular future-horizon transfer.
3. The diagonal one-wall Hamiltonian and invariant Kasner diagnostics.
4. The contracting Liouville layer and finite-wall canonical connection map.

Exploratory reductions, global polar responses, research logs, manuscript
sources, and review materials are absent. No public code depends on them.

`MANIFEST.json` records every distributed file, its byte length, SHA-256, role,
and regeneration command. A full reconstruction writes only to the ignored
`build/` directory and compares its output with the committed data.
